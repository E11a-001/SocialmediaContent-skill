# 三平台差异

同一个母观点，不要平均切三份。三个平台的工作不同。

## 一眼总表

| 平台 | 默认目标 | 最重要的事 | 最容易死的地方 |
|---|---|---|---|
| `X` | 打出判断、引发讨论、沉淀短表达 | 首条是否能立住 | 空喊观点、后续没推进 |
| `小红书` | 点击、停留、建立信任 | 标题 + 开头 + 可学性 | 标题猛、正文空 |
| `博客` | 沉淀长期资产、完整表达 | 论证完整度 | 写成没重点的流水账 |

## `X`

把它当成：

- 思考记录器
- 观点试验场
- 后续内容素材池

适合：

- 单点判断
- 连续推进的 thread
- 短句金句
- 反驳和补刀

不适合：

- 过长铺垫
- 没重点的背景介绍
- 一条里塞太多动作

推荐结构：

1. 第一条立结论
2. 第二条解释误区
3. 第三到第五条给过程或拆分
4. 中段放例子
5. 尾段做收束或反问

## `小红书`

把它当成：

- 学习心智平台
- 标题和开头决定命运的平台
- 更依赖包装完成“人货匹配”的平台

适合：

- 有明确收获感的内容
- 有步骤、有判断、有案例的内容
- 用户愿意收藏或转发给朋友的内容

不适合：

- 纯抒情
- 只有立场、没有方法
- 开头过慢

推荐结构：

1. 标题先帮读者判断“值不值得点”
2. 开头前几行先帮读者判断“值不值得看下去”
3. 正文一段一个动作
4. 结尾给明确互动动作

## `博客`

把它当成：

- 最完整的母稿容器
- 搜索和长期资产的承接地
- 能保留你原始思考链条的地方

适合：

- 更完整的推理
- 更细的案例
- 对反方观点的处理
- 可以被以后继续引用和拆分的内容

不适合：

- 强行做平台感很重的标题党
- 拖沓地重复同一个判断

推荐结构：

1. 导语先立核心判断
2. 主体分 3-5 个层次展开
3. 至少处理一个误解或反例
4. 结尾回到读者动作

## 改写顺序

默认顺序：

1. 先母稿
2. 再博客
3. 再 `X`
4. 再小红书

原因：

- 博客版最完整，先把逻辑撑开
- `X` 适合把母稿掰成一连串短动作
- 小红书最看包装，最后针对点击和留存做压缩

如果用户更在乎短平台，也可以改成：

1. 母稿
2. `X`
3. 小红书
4. 博客

## 三平台必须保持一致的东西

- 核心判断不能变
- 反对的错误对象不能变
- 例子的逻辑作用不能变
- 结论不能为了平台而自相矛盾

## 三平台允许不同的东西

- 开头强度
- 节奏
- 句子长度
- 背景铺垫量
- CTA 形式
